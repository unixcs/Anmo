## v2.2.0 — 2026-09-30（密码登录体系 + 服务记录 + 散客快速结算 + 到店体验）

标签：`v2.2.0`；分三批完成（第一批 2026-09-29，第二/三批 2026-09-29/30）。总体计划见 `docs/2026929plan.md`；已拍板范围：服务记录本期先做（技师独立账号不做，店主本人即唯一技师）、H5 切手机号+密码（短信下线）、新增散客快速结算。

### 第一批：到店与预约体验

- **预约页底部固定提交条（H5 + 小程序）**：提交按钮固定悬浮（适配 iPhone 底部安全区，H5 让开 tab 栏），未选完置灰并提示「请先选择服务/日期/上午或下午」，按钮上方独立摘要行（模糊预约显示「店家安排时间」），内容区底部预留不被遮挡。
- **后台门店经纬度地图选点（admin）**：门店信息卡新增「地图选点」——高德 JS API 弹窗（地址搜索点选回填 / 点击地图拖拽选点 / 无结果引导拖拽 / 确认才回填，6 位小数）；新增「高德地图配置」（`amap_js_key` / `amap_js_code`，服务端校验 ≤64 并 trim 落库，永不下行顾客端）；手动输入保留 + 范围校验（经度 73~135、纬度 3~53）。高德 Key 需商家在高德开放平台免费申请并配置域名白名单，未配置时地图按钮提示、手动输入不受影响。
- **H5 门店地址跳转兼容**：`uri.amap.com` 标准 URI + 坐标合法性前置校验（非法/缺失自动改用地址搜索链接）；跳转后约 3 秒未离开页面则在卡片内出现兜底条（新窗口重试 / 复制地址 / 高德搜索），修复 Via 等移动浏览器裸跳失效问题。不做 iframe 内嵌（高德拒绝被嵌，属计划允许的降级层）。
- **资料完善三件套（H5 + 小程序）**：我的页完善度提示条（姓名/手机号各 50%，已完善隐藏）；预约提交时资料不全弹半屏提示（「去完善 / 先跳过」，跳过一次后不再弹，去完善往返已选保留）；首登提醒弹窗走后台开关 `profile_first_login_prompt`（默认关，仅提示一次）。"只弹一次"均存客户端本地，不进后端。

### 第二批：H5 手机号+密码登录体系（短信下线，D25 修订 / D27）

- **member 表重建（migration 014）**：`phone` 放宽可空（纯微信会员无手机号）、新增 `password_hash`（bcrypt DefaultCost，6~64 位）；升级路径测试覆盖（defer_foreign_keys 重建模式）。
- **H5 注册/登录**：`POST /api/auth/register` / `login`（手机号+密码），错误码与文案细分（未注册/未设密码/密码错误；撞微信号引导去小程序设密码）；登录页改为登录⇄注册一体。
- **小程序纯微信登录**：`POST /api/auth/wx/login` 首登 openid 未绑定时**同事务直建号直发 Token**（D25 bind_ticket 流程废除，`/api/auth/wx/bind` 端点删除）；D24 dev 兜底（openid="dev:"+code）保留，正式发布前必须配置真实凭据。
- **撞号密码认领**：`POST /api/auth/wx/claim`（顾客 Token + 该手机号 H5 密码）转绑老账号，同事务校验空壳无业务数据后删除（uk_member_wx_openid 唯一兜底并发）；小程序「我的」录手机号撞号时引导输入 H5 密码认领。
- **密码管理**：小程序设/重置 H5 密码 `PUT /api/me/h5-password`（需已绑手机号）；admin 会员详情重置密码 `PUT /admin/members/{id}/password`（含 has_password / wx_bound 徽标）。
- **SMS 端点下线**：`sms.mode` 仅 dev|off——dev 过渡期保留（固定 123456），**生产必须 off**（off 时 410 SMS_DISABLED），关闭"任意手机号+123456 登录"的 dev 默认洞；config.example.yaml 与部署 runbook 同步标注。

### 第三批：服务标签 / 服务记录 / 服务追踪 / 散客快速结算（D28 / D29）

- **migration 015**：新建 `service_tag`（BODY_PART/METHOD 两组，uk(group,name)）与 `service_record`；`payment` 重建放宽 `member_id` 可 NULL（006/010 全部约束、唯一索引、生成列、触发器原样保留，升级路径测试覆盖）。
- **服务标签管理（admin 新页）**：调理部位/服务方式两组独立管理——添加（同组同名 409）、停用/启用、上移/下移排序；删除仅限从未被使用（409 TAG_IN_USE 引导停用）；**停用标签不在核销录入页出现、但在历史筛选器仍可见可筛**；历史记录存标签名快照，不受标签增删影响。同页编辑「技师备注快捷短语」（settings KV `service_note_presets`，≤20 条×50 字，服务端校验+清洗）。
- **服务记录（D28）**：预约卡核销 / 散客卡核销 / 现金·微信结算 / 散客快速结算四个入口，同事务生成服务记录——实际调理部位（多选 ≤3）、服务方式（单选）、技师备注（快捷短语点填）、服务名快照；全部选填不阻断核销；**「服务前已完成沟通」强制勾选**（缺省 400 TX_NEED_CONFIRM）。商家与技师备注独立展示、各记操作人与时间；记录为商家内部数据，顾客端不可见。
- **核销撤销联动**：核销撤销事务内同步将服务记录置 REVERSED（不再计入档案与汇总）；撤销后可重新核销（新记录）。
- **散客快速结算 `POST /admin/walkin/settle`（D29）**：无预约无卡——录手机号自动建档/匹配 + 记录归档 + last_visit；**不录手机号仅记账**（payment.member_id NULL、响应 record_skipped，不生成记录与档案）；收款方式现金/微信/其他（CARD 拒绝）；金额默认服务价可改、整数分；idempotency_key 幂等回放；收款列表空会员显示「未登记」。
- **散客记录独立撤销**：`POST /admin/service-records/{id}/revoke`——同事务记录 REVERSED + 原收款 VOIDED；卡核销记录拒绝并引导走核销撤销（还卡次数）。
- **会员详情「服务追踪」**：按时间倒序展示（部位/方式/近1月/近3月/全部筛选 + 备注关键词搜索）；汇总卡（近3个月共 N 次 + 部位/方式计数，REVERSED 不计）；商家备注追加/编辑。
