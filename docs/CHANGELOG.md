# Changelog

记录对外可见的版本收口。更细的决策与过程见 `.trellis/workspace/anmo-agent/journal-*.md` 与任务归档。

## v2.1.0 — 2026-09-29（首页可配置化与小程序体验修复）

标签：`v2.1.0`；提交：`e073b69`（server）→ `65dee67`（apps）→ `fd296f8`（spec）→ `ed39664`（归档）。

### 新增

- **首页服务推荐商家可配置**：后台「内容管理 → 系统设置」新增配置卡——显示数量 2/4/6/8（默认 6）、展示服务勾选 + 上移/下移排序；不勾选 = 按服务排序自动取前 N 张，在架服务不足时自适应全展示。实现走 `content_system_setting` KV（键 `home_service_limit` / `home_service_ids`），零 migration；服务端校验（枚举 / JSON 字符串数组 ≤50）+ 下发清洗，顾客端缺省/脏值一律回落默认。H5 与小程序 `pickHomeServices` 逐行同构。
- **小程序「服务」Tab**：新增 `pages/services`（按分类分组、预约带预选服务），tabBar 对齐 H5 为 首页/服务/预约/我的；首页"服务推荐"补「全部服务」入口。

### 修复

- 小程序登录页手机号/验证码占位文字垂直截断（`.input` 显式 `height: 48px`，微信原生 input 需显式高度）。
- 小程序关于页补齐营业时间展示（对齐 H5）。
- H5「我的」页今日预约过滤误比较函数对象（`todayStr` → `today`）。

### 验收

- trellis-check 全量检查通过；`go build/vet/test`（含 3 组新测试）、H5/admin `vue-tsc` 构建全绿。
- 墨菲对抗式验收（真实服务 + 临时库）：17 项 API 检查 + 10 场景矩阵全部通过。
