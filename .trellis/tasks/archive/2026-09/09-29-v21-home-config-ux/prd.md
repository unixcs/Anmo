# PRD — V2.1 首页可配置化与小程序体验修复

> 来源：用户 2026-09-29 反馈 4 项问题 + 整体打磨 + 墨菲定律对抗式验收。
> 定位：个人到店按摩店，店主唯一服务人员；歧义选"不做"。

## 背景与问题

1. **首页服务推荐冗长**：H5 硬编码 `slice(0, 6)`，小程序显示全部 ACTIVE 服务。服务增多后首页过长，门店信息被推到屏外。
2. **门店电话不可见/不可配**：门店信息卡（定位 logo 下手机号行）两端代码已存在，但仅在 `shop_phone` 已配置时显示；用户环境未见电话行。需保证"地址 + 电话"两行内容都可由商家后台自定义并真实生效。
3. **小程序登录页占位文字截断**：手机号/验证码输入框占位文字只显示上半部分。根因：`app.wxss .input` 无显式 height，微信原生 input 组件垂直居中异常。
4. **小程序缺"服务" Tab**：H5 为 首页/服务/预约/我的 四 Tab，小程序只有 首页/预约/我的 三个，且无服务列表页。

## 需求（验收标准）

### P1 首页服务推荐商家可配置

- 商家后台（内容管理 → 系统设置）可配置：
  - **显示数量**：2 / 4 / 6 / 8；未配置默认 6（兼容现状）。
  - **展示哪些服务 + 排序**：从 ACTIVE 服务中勾选并排序（上移/下移）；未勾选任何服务 = 按服务默认排序（sort, created_at）取前 N 张。
- 顾客端（H5 + 小程序）首页"服务推荐"应用同一套筛选逻辑：
  1. `home_service_ids` 非空 → 按 ID 列表顺序展示（自动跳过已删除/下架服务）；
  2. 否则 → 全部 ACTIVE 服务按默认排序；
  3. 统一截取前 `limit` 张；实际服务少于 limit 时全部展示（自适应）。
- 两端口径一致；服务跳转预约页带预选服务（现有行为不变）。
- 后端仅复用 `content_system_setting` KV（新键 `home_service_limit`、`home_service_ids`），**无 migration、无新实体**。

### P2 门店信息（地址 + 电话）可自定义且真实生效

- 后台已有表单（门店电话/地址/经纬度）保持；补充提示文案说明保存后顾客端首页/关于页立即生效。
- 顾客端验证链路：后台保存 `shop_phone` → H5 首页门店信息卡、H5 关于页、小程序首页门店卡、小程序关于页均出现"手机号 logo + 电话 + 拨打"；未配置时不渲染空行。
- 小程序关于页补齐营业时间展示（对齐 H5 AboutPage，目前缺）。

### P3 小程序登录输入框占位截断修复

- `app.wxss .input` 显式 `height`（48px，与现有视觉尺寸一致），消除占位文字垂直裁切。
- 影响面：登录页手机号/验证码框、我的页昵称输入框（同一全局类），布局不得回退。

### P4 小程序补"服务" Tab

- 新增 `pages/services` 页面：按分类分组展示服务（对齐 H5 ServicesPage：名称/描述/时长/价格 + 预约按钮），点预约带预选服务进预约 Tab。
- `app.json`：注册页面 + tabBar 在"首页"与"预约"之间插入"服务"（文字样式与现有三个 Tab 一致，无图标）。
- 小程序首页"服务推荐"区块头加"全部服务"入口 → switchTab 到服务 Tab（对齐 H5）。

### 整体打磨（第一性原理，剃刀）

- 完成上述后对顾客端展示/预约动线与商家后台做一次整体式审查，只做顺手性微调，不引入新实体。

## 边界 / 不做

- 不做：首页装修拖拽、富文本装修器、Banner 装修、按访客个性化推荐、后端聚合 home services 接口改造（settings + 客户端筛选已足）、地图 SDK、新数据库表。
- 不改变 `/api/services`（目录）语义——预约页仍需全量服务。
- 服务端不感知"首页展示"业务：它只存储/校验/下发两个 settings 键。

## 验收方式

1. `go build ./... && go vet ./... && go test ./...` 全绿（含新增 settings 校验/下发测试）。
2. admin、customer 两个 Vite 构建成功（含 vue-tsc 类型检查，若有）。
3. weapp：app.json 合法（4 Tab）、services 页面四件套齐全、与 H5 信息架构一致。
4. 场景矩阵（墨菲）：limit∈{2,4,6,8,未配}×ids∈{空,含失效ID,数量>limit,数量<limit}；phone∈{空,已配}；输入框 11/6 位占位完整；断网/接口失败回落默认。
