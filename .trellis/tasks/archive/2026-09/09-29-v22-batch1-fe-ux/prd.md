## R1 预约页底部固定提交按钮（weapp + H5 同步）

现状（已核实）：提交按钮在页面流末尾，选完所有项必须下滑才能看到；已选信息塞在按钮文案里。

要求：
1. 提交按钮固定在页面底部悬浮常驻，不随内容滚动；适配 iPhone 底部安全区（`env(safe-area-inset-bottom)`）；页面内容区底部加留白，最后一个选项不被遮住。
2. 未选完（服务/日期/上午下午）按钮置灰不可点，按钮区提示"请先选择服务 / 日期 / 上午或下午"。
3. 按钮上方一行小字展示已选核心信息（如"全身按摩 · 9月30日 上午 10:00"）；模糊预约（未选具体时段）显示"… · 店家安排时间"。
4. 备注键盘弹起可遮挡按钮（接受，不做处理）；不做自动滚动。
5. 预约成功态（success 页）不受影响。
6. weapp 与 H5 预约页两端同步实现；H5 的固定条不得遮挡/被底部 tab 栏遮挡。

验收：
- [ ] 不选任何项时按钮置灰并提示"请先选择服务"；每补齐一项提示随之更新
- [ ] 选完后按钮高亮，上方信息行正确显示已选服务与时间
- [ ] 只选上午/下午（模糊）时信息行含"店家安排时间"
- [ ] 页面滚到底/顶，提交按钮始终可见；iPhone 底部横条不挡按钮
- [ ] 预约成功页无固定条残留

## R2 后台门店经纬度地图选点（admin）

现状（已核实）：ContentPage 门店信息仅有两个手动经纬度输入框。

要求：
1. 表单新增「地图选点」按钮，弹出内嵌高德地图弹窗：支持地址搜索（结果列表点选回填 lng/lat）与拖拽标记选点（点"确认选点"才回填）；搜索无结果提示改用拖拽。
2. 高德 JS API Key 从商家后台设置读取（设置键见 design），未配置 Key 时按钮可点但弹窗提示"未配置高德 Key，请在系统设置中填写"；手动输入兜底始终可用。
3. 手动输入范围校验：经度 73~135、纬度 3~53，超出提示"请输入正确的经纬度"；保存时自动保留 6 位小数（四舍五入）。空值允许（现状允许不填）。

验收：
- [ ] 搜索"地址关键词"→ 列表点选 → 经纬度输入框被回填
- [ ] 拖动标记后必须点"确认选点"才回填，取消不回填
- [ ] 经度 999 或纬度 -3 被拦截并提示
- [ ] 输入 120.123456789 保存后变 120.123457
- [ ] 未配置 Key 时给出明确提示，不影响手动输入

## R3 H5 门店地址跳转兼容（apps/customer ShopCard）

现状（已核实）：`uri.amap.com/marker` 拼接 + `window.location.href` 裸跳，无校验无兜底；用户反馈 Via 等移动浏览器跳转失效显示空白/默认北京。

要求：
1. 点击地址行触发跳转；有坐标且校验通过（经度 73~135、纬度 3~53）→ 高德 marker URI（带 name）；坐标缺失/非法 → 高德 search URI（关键词=完整地址文本）。
2. 跳转后 best-effort 失败检测：约 3 秒后页面仍未离开 → 在卡片内展示兜底条，包含：① 重试跳转链接（新窗口）② 「复制地址」按钮 ③ 高德搜索页链接。纯前端实现，不依赖 iframe（高德页面大概率拒绝被嵌，计划本身允许该层失败降级）。
3. 微信内置/普通浏览器不分支特判，统一标准 URI（callnative=1）。

验收：
- [ ] 有合法坐标：跳 marker URI；坐标为 0/超界/缺失：跳 search URI
- [ ] 模拟跳转失败（如拦截跳转）后兜底条出现，三个操作可用
- [ ] 复制地址写入剪贴板并给出反馈

## R4 资料完善三件套（weapp + H5）

完善定义：`member.name` 与 `member.phone` 均非空 = 100%；填一个 = 50%。

1. 个人中心进度条（默认开启，无后台开关）：头像下方矮提示条；未完善显示"资料完善度 50%｜完善手机号，方便预约联系 [去完善]"（文案按缺失字段变化）；已完善隐藏该条。不弹窗不挡操作。
2. 预约半屏提示（默认开启）：点提交预约时若资料不全，弹轻量半屏："填写手机号，方便技师联系您确认预约。[去完善] [先跳过，继续预约]"；每个用户只提示一次（本地存储标记，跳过后永不再弹）；跳转完善页返回后预约页已选信息全部保留；已完善用户永不弹。
3. 首登弹窗（后台开关，默认关）：设置键 `profile_first_login_prompt`（"1"=开）；开启后未完善用户进入时提示一次完善资料，拒绝/关闭后不再弹（本地标记）；已完善不弹。

验收：
- [ ] 姓名/手机号只填一个 → 进度条显示 50% 与对应文案；全空 → 0% 提示；全填 → 进度条消失
- [ ] 资料不全时点提交：第一次弹半屏，"先跳过"后继续提交且永不再弹
- [ ] "去完善"往返后预约页已选服务/日期/时段保持
- [ ] 后台开关默认关；开启后未完善用户提示一次，之后不再弹
- [ ] 已完善用户任何场景均无提示
